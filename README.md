# portfolio

투플러스원 개인 업무(홈페이지 제작) 포트폴리오 사이트 모음. 사이트마다 폴더 하나.

| 폴더 | 사이트 | 만든 방식 | 옛 저장소 |
|---|---|---|---|
| `noire/` | NOIRÉ 향수 브랜드 | HTML 한 장 (`netlify.toml` 있음) | `2plus1-biz/NOIR-` |
| `ongyeol/` | 온결 필라테스 — https://tpo-ongyeol.netlify.app/ | Vite + TypeScript (AI Studio) | `2plus1-biz/ongyeol-pilates` |
| `pieonada/` | PIEONADA 피어나다 플로럴 아틀리에 | Vite + TypeScript (AI Studio) | `2plus1-biz/PIEONADA` |

- 학습·실습용 가상 브랜드이며 고객 프로젝트가 아니다
- 옛 저장소의 수정 기록은 각 폴더에 그대로 합쳐 두었다 (`git log -- <폴더>`)
- Netlify는 사이트마다 따로 연결하고, Base directory를 그 폴더 이름으로 지정한다
- 새 실습 사이트는 폴더를 하나 더 만들어 추가한다
